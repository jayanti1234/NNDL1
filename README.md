# NNDL Lab Experiments – Natural Language Processing

## 📌 About the Project

This repository contains practical experiments related to Natural Language Processing (NLP) using Python. It covers text preprocessing, language modeling, parsing, named entity recognition, sentiment analysis, and basic neural language models.

The experiments use libraries such as **NLTK, spaCy, NumPy, Scikit-learn, and TensorFlow/Keras**.

## 🎯 Objectives

- Understand the basic concepts of Natural Language Processing.
- Perform text preprocessing and tokenization.
- Analyze words and sentences using statistical language models.
- Explore syntactic parsing and named entity recognition.
- Perform sentiment analysis and sentence similarity analysis.
- Build a simple feed-forward neural language model for next-word prediction.

## 🧪 Experiments Included

| Experiment | Description |
|---|---|
| 1. Tokenization and N-grams | Perform word tokenization and generate unigrams, bigrams, and trigrams. Calculate sentence probability using a bigram model. |
| 2. Stopword Removal | Remove common English stopwords using NLTK. |
| 3. Stemming | Reduce words to their root forms using Porter Stemmer. |
| 4. POS Tagging | Identify parts of speech, such as nouns, verbs, and adjectives. |
| 5. Lemmatization | Convert words into their base dictionary forms using WordNet Lemmatizer. |
| 6. TF-IDF | Calculate term frequency and inverse document frequency. |
| 7. CYK Parsing | Implement the CYK parsing algorithm to check whether a string is accepted by a grammar in Chomsky Normal Form. |
| 8. Language Model Probability | Calculate the probability of a sentence using a bigram language model. |
| 9. Chunking | Identify noun phrases using POS tags and NLTK's RegexpParser. |
| 10. Named Entity Recognition | Identify entities such as people, organizations, and locations using spaCy. |
| 11. IDF Calculation | Calculate inverse document frequency using the NLTK Gutenberg corpus. |
| 12. Language Model Evaluation | Calculate vocabulary coverage and perplexity using a bigram language model. |
| 13. Next-Word Prediction | Build a feed-forward neural language model using TensorFlow/Keras. |
| 14. Sentiment Analysis | Classify text as positive, negative, or neutral using VADER. |
| 15. Text Coherence | Measure sentence similarity using Bag-of-Words vectors and cosine similarity. |
| 16. Cohesive Devices | Identify conjunctions, reference words, and repeated lexical links in text. |

## 🛠️ Technologies Used

- **Machine Learning:** Scikit-learn
- **Deep Learning:** TensorFlow/Keras
- **Numerical Processing:** NumPy
